# e-plantShopping — Paradise Nursery

**Project Name:** e-plantShopping  
**Application Name:** Paradise Nursery

Paradise Nursery is a React plant-shopping application where users browse indoor plants by category, add plants to a cart, adjust quantities, remove items, and view the total cost.

## Features
- Landing page with “Welcome to Paradise Nursery” and “Get Started”
- About Us page
- Three plant categories with six unique plants each
- Plant images, names, descriptions, and prices
- Add to Cart button disables after adding a plant
- Home, Plants, and Cart navigation
- Dynamic cart quantity indicator
- Cart quantity controls, Delete, total amount, Checkout alert, and Continue Shopping
- Redux Toolkit state management

## Run locally
1. Install Node.js LTS.
2. Run `npm install` in this folder.
3. Run `npm run dev`.
4. Open the local URL printed by Vite.

Technologies: React, Vite, Redux Toolkit, React Redux, CSS.
